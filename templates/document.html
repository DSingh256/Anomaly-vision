🗃️ MVTec AD Dataset

MVTec AD is the benchmark for industrial anomaly detection. It contains over 5,000 high-resolution images across 15 object and texture categories. Each category includes defect-free training images and a test set with various defect types plus defect-free baselines.

↗ MVTec AD Dataset

📝 PatchCore Paper

PatchCore addresses the cold-start problem in manufacturing defect detection: training only on nominal (defect-free) images. It builds a maximally representative memory bank of patch features from a pre-trained ImageNet backbone, then measures test-time patch distances to detect and localise anomalies.

📊 Key Result

On MVTec AD, PatchCore achieves 99.6% image-level AUROC, more than halving the error rate of the next-best method at the time of publication.

🚀 Deployment

The application ships with a Dockerfile and docker-compose for one-command deployment.

🐳 Quick Start

  • docker-compose up --build — build & run the full stack
  • Access the dashboard at http://localhost:8000
  • Models are persisted in the models/ volume
